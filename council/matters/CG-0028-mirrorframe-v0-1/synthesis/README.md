# Synthesis

Synthesis artifacts are derivative assemblies for Operator review. They are not decisions.

Each synthesis must declare:

- synthesis ID and author
- creation timestamp
- every source position ID in `derivedFrom`
- agreements observed
- unresolved disagreements
- missing required reviews
- requested Operator decision

A synthesis may compress language for comparison, but it must preserve links to immutable originals and may not restate disagreement as consensus.
