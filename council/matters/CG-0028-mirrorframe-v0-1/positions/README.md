# Positions

Store each substantive contribution as an immutable attributed record.

Required metadata:

- stable `POS-####` ID
- matter ID
- author and role
- position kind and stance
- timestamp
- source form and reference
- response and supersession links
- path to the preserved original content

Revisions create new position records. They do not overwrite prior positions.

Conflicting positions must remain visible until the Operator records a disposition or an attributed author explicitly supersedes a prior position.
