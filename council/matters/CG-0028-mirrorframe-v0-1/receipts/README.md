# Receipts

Receipts record transport and registration facts without interpreting substantive meaning.

Permitted receipt types:

- dispatch
- delivery
- ingestion
- artifact registration
- workflow transition

Each receipt should identify the matter, sender, recipient, timestamp, source reference, destination, and delivery result.

Hermes may create and maintain receipts. A receipt does not imply agreement, review completion, synthesis, disposition, ratification, or canon authority.
