Canonical source means the preferred current source for the stated responsibility. It does not mean every repository listed here has execution authority.

## Source Precedence Rule

When sources disagree:

1. Operator dispositions and ratified governance determine authority.
2. Verified current implementation determines executable behavior.
3. Merged governed records determine recorded system state within their stated scope.
4. Runtime evidence and generated traces establish observed execution facts.
5. Documentation and historical contracts must not override contradictory current implementation evidence.

A dashboard, README, copied contract, repository name, local listener, or historical port assignment must not be treated as current truth without verification.

Conflicts are reconciliation events, not permission to silently choose a preferred source.
