## Required fields for the final registry

Each identity record should eventually include:

- stable identity ID;
- class: human Operator, MIRRORNODE node, collaborating intelligence, service, or repository surface;
- human-readable name;
- role / operating responsibility;
- authenticated service identities;
- demonstrated capabilities;
- verified permissions and scopes;
- governance authority envelope, if any;
- runtime execution authority envelope, if any;
- review/verdict responsibility, if any;
- prohibited actions and escalation triggers;
- connected systems and custody boundaries;
- evidence references;
- reliability history where operationally relevant;
- last verification time and method;
- current assignments and recent action receipts;
- expiry/review date for temporary permissions.
